# Divulgaciones defensivas / arte previo (borradores listos para publicar)

Borradores **habilitantes**, fechables y públicos de las estrategias, esquemáticos, instrucciones y diseños del proyecto OPGPU, destinados a **uso libre universal (dominio público, objetivo CC0 1.0)** y a actuar como **divulgación defensiva / arte previo** para dificultar la apropiación registral (patentes/registros) por terceros de lo divulgado.

- **Alcance:** conceptual/simulado, no validado experimentalmente, no listo para fabricación/certificación. Sin garantía; sin libertad de operación (FTO) garantizada; marcas solo nominativas.
- **Sin conflictos:** basados en obra original del proyecto; excluir cualquier material de terceros no autorizado antes de enviar/publicar (p.ej. datos espectrales de PhotochemCAD no se redistribuyen).
- **Uso:** publicar en ip.com (defensive disclosure), Zenodo (registro/depósito por versión o por estrategia), repositorio público y archivos (Wayback). Completar campos `[FECHA]`, `[AUTORES/TITULARES]`, `[VERSIÓN/COMMIT]`, `[DOI/URL]`, `[ID DISCLOSURE]` al publicar.
